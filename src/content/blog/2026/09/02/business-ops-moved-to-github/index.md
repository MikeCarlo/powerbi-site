## Business Ops Is Now on GitHub

[Business Ops](https://github.com/MikeCarlo/BusinessOps) has moved from the PowerBI.tips Products area to its official GitHub home: [github.com/MikeCarlo/BusinessOps](https://github.com/MikeCarlo/BusinessOps).

Business Ops is a Power BI Desktop companion that helps you install, update, launch, and manage community-built [Power BI external tools](https://learn.microsoft.com/power-bi/create-reports/desktop-external-tools). It is designed to make useful tools such as DAX Studio, Tabular Editor, Bravo, and Report Analyzer easier to discover and maintain.

## Why We Moved It

GitHub is a better home for an open-source utility. Moving Business Ops there improves distribution, gives users a direct place to find releases and report issues, and makes ongoing code management simpler for maintainers and contributors.

The repository is now the source of truth for the project, including its code, release history, installation guidance, and future updates.

## What Is Business Ops?

Business Ops is a single place to manage external tools for Power BI Desktop. External tools extend Power BI development with capabilities for DAX authoring, semantic-model editing, diagnostics, documentation, and report analysis. The GitHub repository includes current setup information and the project version history.
