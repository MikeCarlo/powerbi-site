## How do I filter the data table in Power BI Desktop's Data view?

**TL;DR.** The June 2018 Power BI Desktop release added filtering to the Data view. Drop-down icons appear on the data table so you can filter the raw rows loaded into your model, much like an Excel table. The post's video shows it.

### When did Power BI Desktop add data table filtering?

Data table filtering arrived in the June 2018 Power BI Desktop release. I called it the best feature of the year to date, and the post links Microsoft's June 2018 feature summary for the official details.

### Where do the filter controls appear?

In Power BI Desktop, go to the view the June 2018 post calls Data Table. While you are on that view, drop-down icons appear that let you filter the data table. That name and layout come from the 2018 post.

### What is data table filtering useful for?

It helps when you want to look at the raw data that has been loaded into your data model. Filtering lets you narrow the rows you are inspecting without building a visual.

### Will this feel familiar if I use Excel?

Yes, if you like data tables in Excel. The post says you will feel right at home, with a pivot table type feel.

### Is there a video walkthrough?

Yes, the post embeds the PowerBI.Tips tutorial video "Data Table Filtering - My Favorite Feature of 2018" on YouTube. It shows how the feature works.
